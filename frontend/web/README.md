# AeroPulse UI Demo

Premium environmental intelligence frontend demo for Punjab–Haryana–Delhi NCR.

## Run

```bash
cd web
npm install
npm run dev
```

Open http://localhost:5173

## Features

- Dark command-center shell with 9 screens
- MapLibre GL (CARTO dark-matter) + deck.gl layers
- 1 km pollution grid, fires, wind, forecast plume, population
- Hero scenario EVT-1024 (Punjab agricultural burning)
- Demo Mode simulation (~18s scripted incident)
- AI Copilot with evidence citations
- Mock services shaped for future FastAPI `/api/v1/*` integration

## Build

```bash
npm run build
npm run preview
```
