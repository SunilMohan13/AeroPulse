# ADR-0002: H3 resolution 8 as the ~1 km analytical grid

## Status

Accepted

## Context

LLD §12 forbids lat/lon rounding as a primary key and recommends H3 approximating 1 km.

## Decision

Use H3 resolution 8 (average area ≈ 0.74 km²). Store `grid_id` as the H3 index string.

## Consequences

Joins across CPCB, FIRMS, and IMD use the same cell id. A later story may add a dual-resolution overlay.
